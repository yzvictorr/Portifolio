## 📋 Resumo do Projeto

Projeto desenvolvido durante o **3º semestre do curso de Tecnologia em Banco de Dados**.

O projeto teve como objetivo aplicar na prática os conhecimentos adquiridos durante o semestre, envolvendo desenvolvimento de sistemas, banco de dados e trabalho colaborativo.

Através do desenvolvimento da solução, foi possível trabalhar com conceitos de programação, organização de dados e desenvolvimento de funcionalidades para atender ao problema proposto.

---

## 🛠️ Tecnologias e Conceitos

* Banco de Dados
* SQL
* Desenvolvimento de Sistemas
* Programação
* Git / GitHub
* Metodologias Ágeis

---

## 🎯 Contribuições Individuais

Durante o desenvolvimento do projeto, participei das atividades relacionadas à construção da solução.

Entre as principais contribuições estão:

* Desenvolvimento das funcionalidades do sistema;
* Manipulação e organização dos dados;
* Participação nas atividades relacionadas ao banco de dados;
* Colaboração no desenvolvimento das funcionalidades;
* Organização das tarefas da equipe;
* Participação na resolução de problemas encontrados durante o projeto.

---

## 📚 Aprendizados Efetivos

O projeto possibilitou colocar em prática os conhecimentos adquiridos nas disciplinas do semestre.

Durante seu desenvolvimento, pude melhorar minha compreensão sobre bancos de dados, programação e desenvolvimento colaborativo.

Também tive contato com a dinâmica de desenvolvimento de projetos em equipe, aprendendo sobre organização das tarefas, comunicação e divisão de responsabilidades.
