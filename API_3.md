## 📋 Resumo do Projeto

O projeto foi desenvolvido durante o **3º semestre do curso de Tecnologia em Banco de Dados**, tendo como objetivo o desenvolvimento de uma solução para **controle de ponto e acompanhamento das horas trabalhadas de profissionais terceirizados**.

A aplicação foi desenvolvida para facilitar o registro e gerenciamento das jornadas de trabalho, permitindo o armazenamento das informações de entrada e saída dos profissionais.

Além do registro de ponto, o sistema conta com recursos para **cadastro de profissionais e empresas, consulta dos registros, aplicação de filtros, geração de relatórios e visualização de informações por meio de dashboard**.

A solução integra diferentes componentes de uma aplicação, envolvendo **frontend, backend e banco de dados**, permitindo centralizar as informações e facilitar o acompanhamento da jornada dos profissionais.

---

## 🎯 Objetivo

O principal objetivo do projeto foi desenvolver um sistema capaz de substituir processos manuais relacionados ao controle de ponto de profissionais terceirizados.

A aplicação busca facilitar o registro das jornadas e permitir que as informações sejam consultadas e analisadas de forma organizada.

Com a centralização dos dados, torna-se possível acompanhar os registros de entrada e saída, consultar informações por profissional ou empresa e gerar relatórios para auxiliar no controle das horas trabalhadas.

---

## ⚙️ Principais Funcionalidades

### 👤 Cadastro de Profissionais

Permite realizar o cadastro dos profissionais terceirizados que utilizarão o sistema.

### 🏢 Cadastro de Empresas

Permite cadastrar e gerenciar as empresas relacionadas aos profissionais.

### ⏰ Registro de Ponto

Permite registrar os horários de entrada e saída dos profissionais, mantendo um histórico das jornadas realizadas.

### 🔎 Consulta e Filtros

O sistema permite consultar os registros utilizando diferentes filtros, facilitando a localização das informações.

Entre os filtros utilizados estão:

* Data;
* Empresa;
* Profissional.

### 📊 Dashboard

A aplicação disponibiliza informações por meio de um dashboard, permitindo uma visualização mais intuitiva dos dados registrados.

### 📄 Relatórios

Permite gerar relatórios com as informações relacionadas aos registros de ponto.

### ✏️ Correção de Registros

Possibilita realizar correções em registros cadastrados incorretamente.

## 🏗️ Estrutura da Solução

A aplicação foi estruturada utilizando diferentes componentes:

```text
┌─────────────────────┐
│      Frontend       │
│     Interface       │
└──────────┬──────────┘
           │
           ▼
┌─────────────────────┐
│       Backend       │
│      API / Regras   │
└──────────┬──────────┘
           │
           ▼
┌─────────────────────┐
│     Banco de Dados  │
│       MySQL         │
└─────────────────────┘
```

Essa estrutura permite separar as responsabilidades da aplicação, facilitando a organização, manutenção e evolução do sistema.

Participei da integração entre as funcionalidades da aplicação e os serviços disponibilizados pelo backend.

Essa integração permitiu que as informações fossem enviadas, consultadas e atualizadas entre a interface e o banco de dados.

## 📚 Aprendizados Efetivos

O desenvolvimento deste projeto proporcionou uma evolução significativa nos meus conhecimentos relacionados ao desenvolvimento de sistemas.

Pude aprofundar meus conhecimentos em **Java, Spring Boot, SQL e MySQL**, entendendo melhor como essas tecnologias podem ser utilizadas em conjunto para desenvolver uma aplicação.
