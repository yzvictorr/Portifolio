## 📋 Resumo do Projeto

O projeto foi desenvolvido durante o **4º semestre do curso de Tecnologia em Banco de Dados**, em parceria com a Prefeitura de São José dos Campos.

A solução teve como objetivo desenvolver uma aplicação capaz de trabalhar com informações de monitoramento e análise de dados, disponibilizando os resultados de forma visual e intuitiva.

O sistema integra **frontend, backend e banco de dados**, permitindo o processamento e apresentação das informações para os usuários.

Um dos principais recursos desenvolvidos foi a utilização de **mapas interativos**, permitindo representar informações geográficas por meio de arquivos **GeoJSON**.

Essa funcionalidade possibilita visualizar regiões, áreas e zonas diretamente no mapa, tornando a interpretação das informações mais simples e contribuindo para a análise dos dados.

## 🎯 Contribuições Individuais

### 🗺️ Desenvolvimento da Tela de Mapa

Minha principal contribuição no projeto foi o desenvolvimento da **tela de mapa no frontend**.

A funcionalidade foi desenvolvida para permitir a visualização geográfica das informações presentes no sistema.

O mapa possibilita visualizar regiões e zonas utilizando dados estruturados em GeoJSON.

---

### 🌎 Manipulação de Dados Geoespaciais

Trabalhei com arquivos **GeoJSON**, realizando sua integração com o frontend para que as informações geográficas fossem apresentadas de maneira dinâmica.

A utilização desse formato possibilitou representar contornos e regiões diretamente na aplicação.

---

### 🔌 Integração com o Backend

Também participei da integração entre o frontend e o backend.

A aplicação realiza requisições à API para obter as informações necessárias para atualização dos dados apresentados na interface.

---

### 📊 Visualização de Dados

Participei do desenvolvimento das interfaces utilizadas para apresentar as informações de maneira visual.

O objetivo foi facilitar a interpretação dos dados por meio de mapas, gráficos e componentes interativos.

---

### 👥 Trabalho em Equipe

Durante o projeto, participei ativamente do desenvolvimento em equipe, contribuindo para a organização das tarefas, discussão das funcionalidades e resolução dos problemas encontrados durante a implementação.

## 📚 Aprendizados Efetivos

Durante este projeto, pude aprofundar meus conhecimentos em **desenvolvimento frontend e integração entre sistemas**.

Um dos principais aprendizados foi trabalhar com **dados geográficos utilizando GeoJSON**, compreendendo como essas informações podem ser integradas a aplicações web.

Também aprendi mais sobre a comunicação entre **frontend, backend e banco de dados**, entendendo melhor o fluxo das informações dentro de uma aplicação.

Além dos conhecimentos técnicos, o projeto contribuiu para minha evolução em **trabalho em equipe, comunicação, organização e resolução de problemas**.
