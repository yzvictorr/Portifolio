## 📋 Resumo do Projeto

O projeto foi desenvolvido durante o **5º semestre do curso de Tecnologia em Banco de Dados**, em parceria com a **SIATT**.

A empresa possui projetos estratégicos que envolvem diferentes áreas, como engenharia, aquisição de materiais, controle de horas técnicas e gestão de programas institucionais. O principal desafio identificado foi a existência de dados operacionais distribuídos em diferentes sistemas e registros, dificultando a análise integrada das informações.

A solução proposta consiste em uma **plataforma analítica de integração e exploração de dados**, capaz de consolidar informações provenientes de diferentes áreas da empresa e transformar dados dispersos em informações estruturadas e acessíveis.

O sistema tem como finalidade apoiar a análise dos projetos e a tomada de decisões estratégicas, permitindo visualizar informações relacionadas a custos, execução, materiais, horas trabalhadas e histórico dos projetos.

---

## 🎯 Objetivo do Projeto

O objetivo principal é **integrar, estruturar e analisar dados estratégicos dos projetos da SIATT**, permitindo que gestores tenham uma visão consolidada do consumo de recursos, da evolução das atividades e do histórico operacional dos programas.

A aplicação busca facilitar a identificação de informações relevantes por meio de dashboards, gráficos, filtros e pesquisas.

Entre os principais objetivos da solução estão:

* Consolidar dados provenientes de diferentes fontes;
* Padronizar e organizar os dados para análise;
* Garantir a qualidade das informações por meio do processo de ETL;
* Apresentar a evolução histórica dos projetos;
* Permitir análise de custos e execução;
* Apoiar a identificação de riscos de atraso;
* Facilitar a análise de consumo de materiais;
* Permitir análise do tempo gasto em tarefas e projetos;
* Apoiar a tomada de decisão estratégica.

## 🎯 Contribuições Individuais

### 🗄️ Modelagem de Dados

Uma das minhas principais contribuições no projeto foi relacionada à **modelagem de dados**.

Participei da organização das estruturas utilizadas para representar as informações necessárias à plataforma analítica, considerando dados relacionados a projetos, tarefas, materiais, fornecedores, responsáveis, solicitações e execução.

A modelagem foi importante para estruturar os dados de forma adequada para consultas e análises realizadas pelo sistema.

---

### 🔌 Desenvolvimento do Backend

Também participei do desenvolvimento de funcionalidades do **backend**, contribuindo para a implementação de endpoints utilizados para disponibilizar os dados ao frontend.

Essa atividade envolveu a criação e integração de rotas responsáveis por consultar informações armazenadas no banco de dados e disponibilizá-las para as funcionalidades analíticas da aplicação.

O projeto possui endpoints relacionados a diferentes dimensões e fatos utilizados pela plataforma.

---

### 🔎 Barra de Pesquisa

Uma das funcionalidades de frontend em que contribuí foi a **barra de pesquisa rápida**.

Essa funcionalidade está relacionada ao requisito de permitir que o usuário encontre rapidamente informações sobre **projetos, materiais e fornecedores**.

A implementação busca melhorar a usabilidade da plataforma, reduzindo o tempo necessário para localizar informações específicas.

---

### 📊 Análise e Visualização de Dados

Também participei do desenvolvimento de funcionalidades relacionadas à apresentação dos dados.

O projeto possui requisitos para criação de dashboards e visualizações envolvendo:

* Custos dos projetos;
* Risco de atraso;
* Relação entre custo e execução;
* Investimentos por programa;
* Consumo de materiais por projeto;
* Tempo gasto por tarefa e projeto;
* Filtros analíticos;
* Pesquisa rápida.

Essas funcionalidades têm como objetivo transformar os dados consolidados em informações que possam ser utilizadas na análise dos projetos.

---

### 👥 Trabalho em Equipe

Durante o projeto, participei do desenvolvimento colaborativo com os demais integrantes do Dev Team.

O projeto utiliza uma organização baseada em **Product Backlog, User Stories, Sprints, Definition of Ready (DoR) e Definition of Done (DoD)**.

O repositório apresenta três Sprints planejadas, com atividades distribuídas entre os pacotes de requisitos do sistema.

## 📚 Aprendizados Efetivos

Durante este projeto, pude aprofundar meus conhecimentos em **modelagem de dados, desenvolvimento de APIs e integração entre sistemas**.

Um dos principais aprendizados foi trabalhar com uma solução que precisa integrar informações provenientes de diferentes fontes e organizá-las para utilização em análises.

Também pude compreender melhor a importância dos processos de **ETL**, responsáveis pela coleta, tratamento, validação e organização dos dados antes de sua utilização.

Outro aprendizado importante foi o contato com conceitos relacionados a **Data Warehouse**, utilizados para estruturar os dados de forma adequada para consultas analíticas e dashboards.

Além disso, o projeto permitiu ampliar meus conhecimentos sobre o desenvolvimento de funcionalidades de backend e frontend e sobre a integração entre essas camadas.
